# System Monitoring 2.0.1

System Monitoring 2.0.1 is a focused security and release-consistency update. It keeps
the existing standalone architecture and monitoring behavior unchanged.

## Security updates

- Updates Starlette to the patched 1.3.1 line, including fixes for malformed Host and
  request URL handling and bounded URL-encoded form parsing.
- Updates OpenTelemetry API to the patched 1.45.2 line, fixing quadratic-time parsing
  of malformed trace context.
- Audits the complete locked runtime dependency set in continuous integration.
- Adds regression tests for malformed and unexpected Host headers, cross-origin login
  rejection, and security headers on the administrator interface and static assets.

## Release consistency

The application, Python package and API metadata now report version 2.0.1. The existing
`v2.0.0` tag remains unchanged; this patch gives later changes on `main` a distinct
version and release identity.

## Upgrade

Create a verified database backup, deploy the reviewed 2.0.1 image and confirm
readiness, sign-in, one controlled service check and notification status. This release
does not change the SQLite schema. Follow the [backup and rollback](../backups.md) and
[HTTPS deployment](../deployment.md) runbooks.

## Known limits

The release continues to support one administrator, one application process and one
customer per installation. SQLite has no built-in failover. Availability summaries
describe retained checks rather than continuous uptime. Webhook delivery remains at
least once, so receivers must deduplicate stable event IDs.
